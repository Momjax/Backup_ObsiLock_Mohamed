# Documentation Utilisateur - ObsiLock

## 1. Introduction
Bienvenue sur **ObsiLock**, votre coffre-fort numérique personnel. Cette application vous permet de stocker vos documents importants en toute sécurité grâce à un chiffrement de niveau militaire.

## 2. Prise en main
### 2.1 Connexion
- Lancez l'application client ObsiLock.
- Entrez votre adresse e-mail et votre mot de passe.
- Si vous n'avez pas de compte, utilisez le bouton "S'inscrire".

### 2.2 Interface principale
L'interface se compose de trois zones :
1. **Barre latérale** : Accès rapide à vos fichiers, partages et quota.
2. **Explorateur** : Affiche vos dossiers et fichiers.
3. **Barre d'outils** : Boutons pour créer un dossier, uploader un fichier ou partager.

## 3. Utilisation quotidienne
### 3.1 Gérer vos dossiers
- Pour créer un dossier, cliquez sur "Nouveau Dossier" et donnez-lui un nom.
- Vous pouvez naviguer dans les dossiers en double-cliquant dessus.

### 3.2 Ajouter des fichiers (Upload)
- Cliquez sur le bouton "Uploader".
- Sélectionnez le fichier sur votre ordinateur.
- Le fichier est automatiquement chiffré et envoyé sur votre coffre-fort.

### 3.3 Récupérer un fichier (Download)
- Sélectionnez le fichier dans la liste.
- Cliquez sur "Télécharger".
- Choisissez l'emplacement de destination sur votre PC. Le fichier sera déchiffré automatiquement.

### 3.4 Partager un élément
- Faites un clic droit sur un fichier ou un dossier (ou utilisez le bouton "Partager").
- Définissez une date d'expiration si nécessaire.
- Copiez le lien généré et envoyez-le à votre destinataire.

## 4. Quota de stockage
Votre espace est limité (50 Mo par défaut). Vous pouvez suivre votre consommation en bas de l'interface ou dans la section "Mon Compte".

## 5. FAQ
- **Mes fichiers sont-ils vraiment sécurisés ?** Oui, ils sont chiffrés avec LibSodium avant d'être stockés. Personne, pas même l'administrateur du serveur, ne peut les lire sans votre clé.
- **J'ai perdu mon mot de passe.** Pour des raisons de sécurité, la récupération est impossible sans intervention d'un administrateur (si configuré).
